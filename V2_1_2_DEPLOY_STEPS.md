# DualSurveyBot 2.1.2

Загрузите содержимое архива в репозиторий **DualSurveyBot**,
сохраняя папки `handlers` и `utils`. Архив включает предыдущие исправления
запуска анкеты и модулей выгрузки.

Новое в этой версии:

- отзыв студента запрашивает только «Введите название учебного модуля»;
- Мезгов Кирилл Леонидович добавляется в список студентов: поток 2, курс 3,
  специальность «Профессиональное обучение (по отраслям)»;
- если он ранее зарегистрирован под коротким ФИО, сохраняются ID,
  Telegram-регистрация и история анкет;
- студент остаётся в списке после повторных перезапусков бота.

Если версия 2.1.1 уже установлена полностью, для этого изменения достаточно
заменить `fill_students.py`, `handlers/student_feedback.py`,
`handlers/survey.py`. Остальные файлы нужны для полного обновления с более
ранней версии.

После развёртывания проверьте «О программе» — версия 2.1.2. Начните новую
анкету и найдите Мезгова в потоке 2. В отзыве о наставнике поле ввода должно
запрашивать только название модуля.

Сначала обновите LMS до 11.8.1, чтобы ФИО совпало с её существующей карточкой.
Файл `students.xlsx` не заменяется: дополнение применяется при запуске бота.
База данных, токены и существующие пользователи не входят в архив обновления.
