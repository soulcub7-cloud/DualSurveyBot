# DualSurveyBot
Репозиторий для размещения чат-бота для анкетирования наставников сельскохозяйственных предприятий Казахстана

## Связь с CT Assembly Learning Hub

Бот продолжает работать по прежнему сценарию и сохраняет анкеты в собственной
базе. Если заданы переменные Railway, копия каждой анкеты автоматически
передаётся в матрицу компетенций LMS. При временной недоступности LMS работа
бота не прерывается; сохранённые анкеты повторно проверяются каждые 15 минут.

```text
LMS_API_URL=https://ct-assembly-learning-hub-production.up.railway.app
LMS_BOT_INTEGRATION_TOKEN=тот_же_секретный_ключ_что_и_в_LMS
```

Секретный ключ хранится только в Railway Variables и не добавляется в GitHub.
