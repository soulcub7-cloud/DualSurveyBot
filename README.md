# DualSurveyBot
Репозиторий для размещения чат-бота для анкетирования наставников сельскохозяйственных предприятий Казахстана

Текущая версия: **2.1.2**. Порядок установки — `V2_1_2_DEPLOY_STEPS.md`.

## Анкеты предприятий

- для CT Assembly используется профиль из 8 hard skills и 21 soft skills;
- для CT Agro используется профиль из 18 hard skills и 21 soft skills;
- профессиональная пригодность оценивается отдельно и не искажает средний балл компетенций;
- каждая анкета хранит снимок формулировок вопросов, поэтому старые отчёты не меняются после обновления каталога;
- Excel содержит сводку, построчные оценки и комментарии; PDF и индивидуальный Excel используют вопросы выбранного предприятия.

Старая универсальная анкета больше не предлагается для новых оценок. Ранее
сохранённые анкеты остаются доступными в истории и отчётах.

## Анонимный отзыв студента о наставнике

После регистрации студент выбирает себя в списке LMS, затем наставника и
отвечает на 14 оценочных и 6 открытых вопросов. Наставнику показываются только
анонимные итоги. Имя студента доступно лишь администратору в кабинете
специалиста и в административных отчётах Excel/PDF.

Справочник наставников загружается из LMS. Если LMS временно недоступна, бот
использует последнюю успешно загруженную копию справочника. Отзыв сохраняется
локально сразу и повторно отправляется в LMS после восстановления связи.

## Связь с CT Assembly Learning Hub

Бот сохраняет анкеты в собственной базе. Если заданы переменные Railway, копия
каждой анкеты наставника автоматически передаётся в матрицу компетенций LMS, а
отзыв студента — в административный раздел «Отзывы о наставниках». При
временной недоступности LMS работа бота не прерывается; несинхронизированные
записи повторно проверяются каждые 15 минут.

```text
LMS_API_URL=https://ct-assembly-learning-hub-production.up.railway.app
LMS_BOT_INTEGRATION_TOKEN=тот_же_секретный_ключ_что_и_в_LMS
```

Секретный ключ хранится только в Railway Variables и не добавляется в GitHub.
