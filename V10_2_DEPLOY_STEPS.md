# CT Assembly Learning Hub — обновление 10.2

## Что изменено

- Шрифт ФИО в фильтре «Студент» матрицы навыков выровнен с полями «Поток» и «Тип компетенции».
- Название `ST Assembly` заменено на `CT Assembly` во всём интерфейсе и стартовых данных.
- При первом запуске версии 10.2 прежнее название автоматически заменяется в существующей базе Railway, включая ротации, наставников, курсы и связанные записи.

## Как загрузить

1. Распакуйте архив.
2. В репозитории GitHub выберите `Add file` → `Upload files`.
3. Загрузите содержимое распакованной папки с сохранением папки `static`.
4. Нажмите `Commit changes` и дождитесь статуса `Online` в Railway.
5. Обновите страницу сочетанием `Ctrl + F5`.

## Важно

- Файл `lms.db` в архив не включён.
- Загружать базу данных через PowerShell не требуется.
- Данные студентов, наставников, оценок и тестов сохраняются в Railway Volume.
